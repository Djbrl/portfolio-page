# Djibril Sy — Portfolio

Editorial portfolio for Djibril Sy, a product engineer based in Dakar, Sénégal.

## Development

```bash
npm install
npm run dev
```

The local server is available at `http://localhost:3000` by default.

## Production

```bash
npm run build
```

The site is built with Nuxt 3 and uses project assets from the `public` directory.
